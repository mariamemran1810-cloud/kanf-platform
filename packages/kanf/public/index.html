حسابات وصلاحيات

تسجيل ودخول آمن، جلسات موقّعة، وثلاثة أدوار: مالك، مشرف، عضو — مع عزل واضح للصلاحيات.

🤖

الوكيل البرمجي

ساحات حوار متعددة، سياق محفوظ، وعدّاد رموز — مع ربط أي نموذج متوافق مع OpenAI.

📊

لوحة تحكم وإحصائيات

مستخدمون، مشاريع، ساحات، ورموز مستهلكة — كلها محدّثة لحظياً في مكان واحد.

🗂️

مشاريع ونشاط

أنشئ وحرّف وأرشف مشاريعك، مع سجل نشاط كامل لكل إجراء يجري داخل المنصة.

💳

اشتراكات وخطط

ثلاث خطط: تجريبي، احترافي، مؤسسي — جاهزة للربط مع بوابة دفع حقيقية لاحقاً.

🌍

عربي أولاً + إنجليزي

واجهة RTL أصلية بالعربية، وتبديل فوري إلى الإنجليزية من أي شاشة.

ثلاث خطوات للبدء

من التثبيت إلى أول حوار مع الوكيل في أقل من دقيقة.

1

ثبّت وشغّل

bun install
bun run --cwd packages/kanf dev

2

سجّل حسابك

افتح localhost:4040 وأنشئ حساباً جديداً، أو استخدم الحسابات التجريبية الجاهزة.

3

تحدّث مع الوكيل

افتح «الوكيل»، أنشئ ساحة جديدة، واكتب طلبك. أضف مفتاح API لتفعيل نموذج حقيقي.
